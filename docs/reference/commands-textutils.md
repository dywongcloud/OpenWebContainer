# Shell text and file utilities — measured host comparison

Measured on a fresh `git archive origin/main` export (ee1bea4d, built dist), host `/bin/sh` (bash 3.2, BSD/GNU/Info-ZIP utilities) vs one fresh OpenWebContainer boot per case, stdout + stderr + exit code compared at two memory points and each case repeated. One line per command in this shard.

- `paste`: merges columns of files/stdin with `-d`/`-s`, host-identical on data and missing-file cases; `--help` prints the container's own BSD usage rather than the host's illegal-option line (both exit 1).
- `tabs`: emits terminal tab-stop escape sequences, host-identical with no args and `-8`; `--version` is refused with exit 2 where the host writes escape codes and exits 0.
- `tac`: reverses lines of files/stdin, host-identical on data; missing file prints the container's BSD wording, and `--help` is refused with exit 1 where the host's Homebrew GNU tac prints help with exit 0.
- `tty`: reports "not a tty" and `tty -s` exit 1, host-identical in all measured cases.
- `wc`: line/byte/word counts of files and stdin, host-identical in all measured cases.
- `unexpand`: converts leading blanks to tabs on files/stdin, host-identical in all measured cases.
- `tr`: translates, deletes and squeezes character sets host-identically on data; an unknown option such as `--version` is silently accepted with empty output and exit 0 where the host reports `tr: illegal option -- -` with exit 1.
- `xargs`: builds and runs command lines from stdin host-identically for `echo`, empty input and `-n 1`; the attached form `-n1` (also `-n2`, `-L1`, `-I{}`, `-s100`, `-P1`) is refused with `invalid option -- n` and exit 1 where the host runs it.
- `xxd`: hexdumps and reverses hex host-identically on data; `--version` is refused with exit 1 where the host prints its version banner with exit 0.
- `zip`: creates and lists deflate archives host-identically (`zip out.zip f1.txt` then `unzip -Z1` lists the entry on each side); `-v` is refused with exit 2 where host Info-ZIP prints its copyright banner, and bare `zip` writes a raw PK stream to stdout whose timestamp bytes differ from the host's.
- `xz`: `xz`, `unxz` and `xzcat` report `unsupported: no xz codec is available in this build` with exit 2 for every case; the container ships only DEFLATE/gzip/zlib (fflate, pako, jszip) plus brotli/zstd WASM codecs and no LZMA2 codec. The host's xz compresses (`printf "hello world\n" | xz | wc -c` = 76), decompresses, prints GNU `--help` (exit 0) and reports a missing file with exit 1. No xz codec exists anywhere in this repository or its dependencies, so no implementation was added.
- `unrar`: absent on this host (`command not found`, exit 127); the container answers `sh: unrar: command not found` with exit 127 in every case — host-faithful.
- `mktemp`: creates a real 0600 file or 0700 directory in `$TMPDIR` (the container's `/tmp`) and prints its path; supports `-d`, `-u`, `-q`, `-t prefix`, `-p dir` and trailing `XXXXXXXX` templates. Host creates an equivalently random file/directory and prints its path (exit 0); the absolute paths differ only because the two environments have different `TMPDIR` values and independent random suffixes. `mktemp --help` prints the same `unrecognized option` line and usage with exit 1 on both sides.
- `mknod`: `mknod <name> p` creates a FIFO node (`test -p` true, `test -f` false, `ls -l` shows `p`, `stat -c %F` "named pipe") with empty output and exit 0, host-identical; `mknod <name> c 1 3` and `b` report `Operation not permitted` with exit 1, which is also what this non-root host reports, and the container has no kernel device table; bare `mknod` and `--help` print the same BSD usage with exit 1.
- `pv`: absent on this host (`command not found`, exit 127); the container answers `sh: pv: command not found` with exit 127 in every case — host-faithful.
- `quota`: the container answers `sh: quota: command not found` with exit 127, while this host prints `Disk quotas for user <u> (uid N): none` (exit 0) for `quota`/`quota -v` and a usage line (exit 1) for `--help`. The container is one JavaScript process with no kernel quota tables, no `quotactl` and no quota accounting, so emitting a "none" report would fabricate quota state that does not exist; no stub was added.
- `quotacheck`: the container answers `sh: quotacheck: command not found` with exit 127, while this host prints its usage (exit 1) for `--help` and `<mount> not identified as a quota filesystem` (exit 0) for a bad filesystem. The container has no kernel-mounted quota filesystems to scan; no stub was added.
