Symptom
  A failing test's block named the test where host node v24.15.0 prints the place the test was
  registered -- "test at c2.js:3:1" -- and it stopped after the stack, where the host closes the
  block with the error's own properties in braces: generatedMessage, code, actual, expected,
  operator and diff.

Cause
  report printed each failure as the test's bare name above its mark and then the error's stack
  alone; nothing kept the site the test was registered at, and nothing printed the properties an
  error carries of its own.

Fix
  packages/core/src/process/executors/node/runtime/guest/modules/pure-b.ts
    addTest keeps the site of the call that registered the test, read off a fresh Error's stack
    and printed from the working directory as the host prints one; report opens each failure with
    "test at <file>:<line>:<col>" and prints the error through errorText, which indents the stack
    two spaces and closes it with the properties the error carries of its own -- name, message
    and stack are an error's everywhere and are not printed -- with the diff an assertion carries
    behind its operator. A value a test threw that is not an Error stays quoted, as on the host.
